# Stonique S.A.U. — sitio independiente

Portafolio estático en español, inglés y portugués. El archivo `index.html` es la página principal; las otras versiones son `index-en.html` y `index-pt.html`.

Las 43 imágenes se sirven desde este mismo sitio y conservan exactamente los bytes de los originales verificados. `SHA256SUMS.txt` permite comprobar cada archivo. Los píxeles y scripts de seguimiento fueron omitidos en esta copia; el diseño y el contenido del portafolio se conservaron.
