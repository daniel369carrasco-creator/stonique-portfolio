# Stonique S.A.U. — sitio independiente (staging)

Portafolio ES/EN/PT basado en las páginas públicas y con las 43 imágenes originales servidas desde este repositorio. La rama `main` conserva la copia inicial; la rama `staging` recibirá la versión editorial revisada.

## Cómo actualizar
- Edita `index.html` (ES), `index-en.html` (EN) o `index-pt.html` (PT) desde GitHub para cambiar textos. Cada confirmación actualiza la versión de Pages publicada desde la rama de staging.
- Edita `resources.json` para sumar o corregir guías. Los recursos aparecen en la página del idioma correspondiente.
- Para agregar video o audio, sube los archivos a `media/` y agrega una entrada en `resources.json`: `type` puede ser `video`, `audio`, `youtube` o `tutorial`. Los archivos directos se reproducen con controles dentro de la página; YouTube se inserta en el sitio.
- Los formatos directos admitidos son los del navegador, normalmente MP4/WebM para video y MP3/OGG para audio. Mantén archivos ligeros y verifica derechos, subtítulos y descripción antes de publicarlos.
- El formulario comercial está incrustado desde Tally; sus respuestas llegan a la cuenta de Tally asociada al formulario.
